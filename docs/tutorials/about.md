# Course Overview

This course introduces data lake fundamentals using Delta Lake and Polars on AWS S3. You'll learn to read, write, merge, and manage Delta tables in pure Python — no Spark, no JVM, no cluster required.

After completing this course, you'll understand how modern data lake pipelines work: Delta tables on S3 for versioned storage, Polars for high-performance data processing, and patterns like merge/upsert, time travel, and schema evolution that production systems rely on daily.
