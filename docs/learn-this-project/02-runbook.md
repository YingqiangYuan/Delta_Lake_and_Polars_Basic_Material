# 02 — Runbook

## Prerequisites

| Tool | Version | Install command |
|------|---------|----------------|
| Python | 3.12 | `mise install python@3.12` or install via pyenv/system package manager |
| uv | latest | `mise install uv@latest` or `curl -LsSf https://astral.sh/uv/install.sh \| sh` |
| mise | latest | `curl https://mise.run \| sh` (see [mise.jdx.dev](https://mise.jdx.dev)) |
| AWS CLI | v2 | `brew install awscli` (macOS) — needed to configure `aws configure --profile <name>` |
| An AWS account | — | You need an S3 bucket and an IAM user/role with S3 read/write permissions |

## First-time setup

1. **Install mise and tools:**
   ```bash
   mise install
   ```
   This reads `mise.toml` and installs Python 3.12 and uv.

2. **Install Python dependencies:**
   ```bash
   mise run inst
   ```
   This creates `.venv/` and installs all dependencies (core + dev + test extras) via `uv sync --all-extras`.

3. **Configure AWS credentials:**
   ```bash
   cp .env.example .env
   ```
   Edit `.env` and set:
   - `AWS_PROFILE` — your named AWS CLI profile (must already exist via `aws configure --profile <name>`)
   - S3 bucket name and root prefix for Delta table storage

4. **Verify the setup:**
   ```bash
   python examples/00-minimal-poc/s01_minimal_poc.py
   ```
   If this runs without errors and prints a 3-row DataFrame, your environment is working.

## Running locally

This project has no long-running server. Each example script is a standalone program:

```bash
# Run any single script
python examples/00-minimal-poc/s01_minimal_poc.py
python examples/01-delta-read-write/s01_overwrite.py
python examples/02-polars-etl/s01_column_ops.py

# 06-full-etl must run in order
python examples/06-full-etl/s01_bronze_write.py
python examples/06-full-etl/s02_silver_etl.py
python examples/06-full-etl/s03_incremental.py
```

Scripts in `02-polars-etl` are pure in-memory and do NOT require AWS credentials. All other modules require a working AWS profile with S3 access.

**What to expect:** Each script prints its output (DataFrames, row counts, verification messages) to stdout. Scripts in `03-merge-upsert` and `06-full-etl` include assertion-based verification.

## Common failures and fixes

| Symptom | Likely cause | Fix |
|---------|-------------|-----|
| `KeyError: 'AWS_PROFILE'` | `.env` not configured | Copy `.env.example` to `.env` and fill in values |
| `botocore.exceptions.NoCredentialsError` | AWS profile not set up | Run `aws configure --profile <name>` first |
| `botocore.exceptions.ClientError: AccessDenied` | IAM permissions insufficient | Ensure your IAM user/role has `s3:GetObject`, `s3:PutObject`, `s3:DeleteObject`, `s3:ListBucket` |
| `DeltaError` on `mode="error"` write | Table already exists | This is expected behavior in `s03_error_mode.py` — the script demonstrates this error |
| `ModuleNotFoundError: delta_lake_and_polars_basic` | Package not installed in venv | Run `mise run inst` to install with `uv sync --all-extras` |
| Scripts in `06-full-etl` fail | Run out of order | Must run `s01 -> s02 -> s03` sequentially |
| Polars version mismatch errors | Wrong polars version | Check `pyproject.toml` — pinned to `>=1.39.3,<1.40.0` |

## Where to look when something breaks

- **AWS credential issues:** Check `.env` values, then `aws sts get-caller-identity --profile <your-profile>` to verify the profile works.
- **S3 path issues:** Each script prints the S3 console URL (`s3dir_example.console_url`) — open it in your browser to inspect the Delta table files directly.
- **Delta table corruption:** Look at `_delta_log/` directory in S3 — each version is a JSON file. The latest version file shows the most recent operation.
- **Polars errors:** Polars error messages are generally clear. Common issue: schema mismatch between DataFrame and existing Delta table. Check column names and types.
- **mise task failures:** Run `mise tasks ls` to see available tasks. Run tasks with `-v` for verbose output.
